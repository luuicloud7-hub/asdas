# Telegram-калькулятор

Однофайловый Telegram-бот на Python, aiogram 3 и SQLite. Интерфейс бота — на русском языке.

## Требования

- Python 3.10 или новее
- Токен Telegram-бота, созданного через [@BotFather](https://t.me/BotFather)

## Установка и запуск

Создайте виртуальное окружение, установите зависимость и задайте переменную окружения с токеном:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install "aiogram>=3.7"
export BOT_TOKEN="PASTE_TOKEN_HERE"
python calc_bot.py
```

В Windows PowerShell используйте активацию `.venv\Scripts\Activate.ps1` и задайте переменную так:

```powershell
$env:BOT_TOKEN = "PASTE_TOKEN_HERE"
python calc_bot.py
```

Замените `PASTE_TOKEN_HERE` на токен локально. Не добавляйте настоящий токен в код, README или Git-коммиты. Для хостинга задайте `BOT_TOKEN` через хранилище секретов платформы.

Бот работает через long polling. При запуске он удаляет webhook и сбрасывает ожидающие обновления Telegram.

## Команды

- `/start`, `/help` — справка
- `/calc` — открыть калькулятор с кнопками
- `/history` — показать последние 10 вычислений
- `/clear` — очистить историю вычислений пользователя

Также можно отправить выражение обычным сообщением.

## Вычисления

Поддерживаются `+`, `-`, `*` (или `×`), `/` (или `÷`), `//`, `%`, `^`, скобки, константы `pi` и `e`, а также функции `sqrt`, `sin`, `cos`, `tan`, `ln`, `log`, `abs` и `round`. Тригонометрические функции принимают аргументы в радианах.

## Данные

SQLite-файл создаётся автоматически. По умолчанию он называется `calc_bot.db`; другой путь можно задать переменной окружения `DB_PATH`. В базе хранятся настройки текущего выражения и история вычислений каждого пользователя.
